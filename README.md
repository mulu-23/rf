Конференции.РФ

Веб-приложение для регистрации пользователей и бронирования конференц-залов.

О проекте

«Конференции.РФ» — веб-сайт для регистрации пользователей и выбора конференц-залов для проведения мероприятий.

Пользователь может:

зарегистрироваться;
выполнить вход в систему;
просматривать доступные конференц-залы;
выбрать подходящий зал;
оформить бронирование.

Администратор может:

войти в административную панель;
просматривать зарегистрированных пользователей;
отслеживать данные регистрации;
просматривать информацию, поступающую в базу данных.

Запуск проекта
Шаг 1. Установите зависимости (только первый раз)
npm install
Ждёте 1–3 минуты, пока скачаются пакеты. Появится папка node_modules.

Шаг 2. Запустите проект
npm run dev
В терминале появится что-то вроде:
  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  
Шаг 3. Откройте в браузере
Скопируйте адрес http://localhost:5173 и вставьте в браузер.
Сайт откроется.
